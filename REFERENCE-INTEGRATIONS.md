The planned information path is authenticated collection → time-stamped evidence → memory/retrieval and bounded scenarios → specialist analysis → persisted decision → independent qualification and risk admission → one durable broker writer → broker-confirmed fills → holding review/exit → reconciled attribution and learning. Parallel research must converge on one admission and execution authority. Opening a screen must not launch a second trading loop.

For each runtime adapter, acceptance requires a pinned source/version and license review, typed input/output, an observed provider health response, timeout/cancellation and budget behavior, owner authorization, bounded prompt/tool permissions, reproducible temporal tests, and a screen showing actual results or explicit failure. Imported names, installed skills, mock fixtures and healthy public endpoints alone do not establish completion.
