# Rainlight lettering

The interface self-hosts Alike Regular and the IBM Plex Sans variable font.
Both are distributed under the SIL Open Font License 1.1; the original notices
are retained in `Alike-OFL.txt` and `IBMPlexSans-OFL.txt`.

Upstream sources:

- [Alike in Google Fonts](https://github.com/google/fonts/tree/main/ofl/alike)
- [IBM Plex Sans in Google Fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexsans)

The application makes no external font request. The approved first-view
lettering uses Alike for display text and IBM Plex Sans for working controls.
